# يوميات كفو — سكربتات الإنتاج

- `render.py` الحلقة 3 «ماتشين بنفس الوقت» + الدوال المشتركة (الترجمة، الشارة، الختام)
- `eps.py` الحلقة 4 «كفو برّا المحل» والحلقة 5 «الضيف اللي يرجع»
- `sprite.py` شخصية كفو من التصميم الأصلي «شخصية PopupPush — كفو» (SVG)
- `audio.py` / `audio_ep.py` موسيقى ومؤثرات مولّدة (بدون حقوق)

المواصفات: 1080×1920، 30fps، 16 ثانية، H.264 CRF 17، AAC 48kHz، ‎-14 LUFS.
الترجمة بالمنطقة الآمنة (y=1330)، والشارة y=230، والختام 3.5 ثانية.
الخط: IBM Plex Sans Arabic (OFL).

تشغيل: `python3 render.py` ثم `python3 eps.py 4` و`python3 eps.py 5`، وبعدها دمج الصوت بـ ffmpeg مع loudnorm.
